# pine-price-action-indicator
Price action indicator for TradingView (Pine Script v5) that maps market structure (BOS, CHOCH) into tappable zones: TJL, QML, SBR/RBS, DT/DB, D-CHOCH and ISS. Optional FVG, Order Blocks, Kill Zones, MTF trend dashboard, level analyzer and M15/H1/H4 alerts. Educational only, not financial advice.
